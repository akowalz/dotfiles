cmux

tmux-style keys behind a ⌃A prefix: press it, let go, then the key.

Workspace (sidebar entry) › pane (split) › tab

Workspaces

⌘N
New workspace (opens as two side-by-side panes)
⌘J/⌘K
Next / previous workspace
⌃A›A
Jump back to the last one
⌃A›⇧L
Go to a workspace
⌃A›,
Rename it
⌃A›⇧←/→
Move it up / down the sidebar

Panes

⌃A›HJKL
Focus the pane left / down / up / right
⌃A›O
Focus the next pane
⌃A›V
Split right (like vim's :vsplit)
⌃A›S
Split down
⌃A›Z
Zoom the pane full size, and back

Tabs & more

⌘T
New tab in this pane
⌃L
Clear the screen

Shell

zsh, with grey autosuggestions.

Keys

Tab
Take the grey suggestion, or complete when there's none
→or⌃E
Take the grey suggestion
⌃R
Fuzzy-search command history

Claude

claude -c
Continue the last conversation
claude -r
Pick a past conversation to resume
claude --effort low
Effort for this session only (/effort changes the default)

Git

g is git: g st, g sel, …

Everyday

st
Status
sel
Pick a branch with fzf, newest first, and check it out
co -/co -b
Back to the previous branch / start a new one
gp
Pull and prune deleted branches (no g)

Branches

pu
Push this branch and set its upstream
sync
Update main, then rebase onto it
rbm
Fetch main, interactive rebase onto it
rbi
Interactive rebase of just this branch's commits
rbc
Rebase --continue

Commits

amend
Add staged changes to the last commit
redo
Add everything, amend, force-push (with lease)
pushfix
Fixup commit, then push
pile
Stash, untracked files included
staged
Diff of what's staged
copy-sha
Copy HEAD's SHA
reset-to-origin
Throw away local commits, match origin

Review workflow

Every diff viewer is gd + where it opens.

gdv
vim · diffview
Side by side, edit while you review
gdt
terminal · diffnav
A quick look, file tree on the left
gdw
terminal · watching
Live, in a split next to Claude Code
gdc
VS Code · code
One tab, files listed in Source Control
gdgh
GitHub · compare
The branch the way a reviewer sees it
gdt

Nothing: uncommitted changes

gdt b

The whole branch since it left main, uncommitted included (branch works too)

gdt HEAD~3

Anything else goes straight to git
